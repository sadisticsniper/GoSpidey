GoSpidey 🕷️

A small 2D survival game built in Unity for a game jam.

Gameplay - 
Play as a spider building a web while trapping slime bugs for survival.

- Build silk connections between web nodes
- Trap bugs before they escape
- Eat trapped bugs to restore energy
- Survive and manage resources

Features
- Web-building mechanics
- Bug AI with trapping and escape behavior
- Energy management system
- Win/Lose gameplay loop
- UI menus and restart system

Tech Stack
- Unity
- C#
- 2D Physics
